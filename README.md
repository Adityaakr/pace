# PACE DAO Monorepo

Web-first monorepo for PACE DAO.

## Start Development

```bash
pnpm install
cp .env.example .env
pnpm dev
```

`pnpm dev` starts the Expo web app from `apps/web` (package: `@pace-dao/web`).

## Useful Commands

```bash
# Web app
pnpm dev

# Contracts
pnpm contracts:compile
pnpm contracts:test
pnpm contracts:deploy

# Monorepo
pnpm build
pnpm lint
pnpm test
```

## Project Structure

```text
apps/web/            # Web app (Expo + React Native Web)
packages/contracts/  # Hardhat contracts
packages/shared/     # Shared types and utilities
```
